# Система электронного архива

## Назначение

Система электронного архива предназначена для хранения, организации и поиска электронных документов. Приложение позволяет систематизировать документы по категориям, хранить информацию об авторах и управлять архивными данными.

## Целевая аудитория

Система предназначена для организаций, сотрудников и пользователей, которым необходимо хранить, систематизировать и находить электронные документы.

## Предметная область

Предметной областью проекта является электронное архивирование документов.

В системе каждый документ связан с определённым автором и категорией и хранится в архиве. В дальнейшем система будет предоставлять возможность добавления, просмотра, изменения, удаления и поиска документов.

## Основные сущности

* **Документ** — электронный документ, содержащий название, описание и другую информацию.
* **Категория** — группа, к которой относится документ.
* **Автор** — пользователь или сотрудник, создавший документ.
* **Архив** — хранилище электронных документов.

## Основные функции

* добавление документа в электронный архив;
* просмотр информации о документе;
* определение категории документа;
* определение автора документа;
* поиск и работа с документами.

## План развития

На следующих этапах планируется:

* реализация полноценной структуры данных на Python;
* создание классов основных сущностей;
* разработка веб-приложения на Django;
* подключение базы данных;
* реализация связей между сущностями;
* реализация регистрации и авторизации пользователей;
* добавление операций создания, просмотра, изменения и удаления документов;
* разработка REST API;
* написание автоматизированных тестов;
* контейнеризация приложения с помощью Docker;
* настройка CI/CD.
