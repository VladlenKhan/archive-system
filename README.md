# Система электронного архива

Консольное приложение для хранения и обработки информации об электронных документах.

Проект является продолжением индивидуального проекта, разработанного в рамках практической работы №1. Во второй практической работе программа была расширена с использованием коллекций, циклов, функций, пользовательских модулей, обработки исключений, работы с файлами и JSON.

## Возможности

Программа позволяет:

* просматривать список документов;
* добавлять новые документы;
* проверять корректность данных документа;
* искать документы по названию;
* просматривать информацию о документе;
* фильтровать документы по категории;
* сортировать документы по названию;
* удалять документы;
* сохранять данные в JSON-файл;
* загружать данные из JSON-файла при запуске программы.

## Структура проекта

```text
electronic-archive/
├── README.md
├── requirements.txt
├── main.py
├── documents.py
├── storage.py
├── utils.py
├── data/
│   └── documents.json
└── tests/
    └── test_documents.py
```

### Описание файлов

* `main.py` — запуск программы и консольное меню.
* `documents.py` — функции для добавления, поиска, фильтрации, сортировки и удаления документов.
* `storage.py` — загрузка и сохранение документов в формате JSON.
* `utils.py` — вспомогательные функции для пользовательского ввода.
* `data/documents.json` — файл хранения данных документов.
* `tests/test_documents.py` — автоматические тесты основных функций проекта.
* `requirements.txt` — список зависимостей проекта.

## Установка

Клонировать репозиторий и перейти в директорию проекта:

```bash
git clone <URL_репозитория>
cd electronic-archive
```

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Запустить программу:

```bash
python3 main.py
```

После запуска появляется консольное меню:

```text
=== Система электронного архива ===
1. Показать документы
2. Добавить документ
3. Найти документ
4. Показать информацию о документе
5. Найти документы по категории
6. Отсортировать документы
7. Удалить документ
8. Сохранить данные
0. Выход
```

## Тестирование

Для запуска автоматических тестов используется `pytest`:

```bash
pytest
```

Тесты проверяют основные функции работы с документами:

* проверку документа;
* добавление документа;
* поиск документа;
* удаление документа.

## Проверка качества кода

Для проверки кода используется `flake8`:

```bash
flake8 .
```

При отсутствии сообщений об ошибках проверка пройдена.

## Хранение данных

Документы хранятся в файле:

```text
data/documents.json
```

Каждый документ содержит:

* название;
* автора;
* категорию;
* архив;
* размер;
* дату добавления;
* статус нахождения в архиве.

При запуске программы данные загружаются из JSON-файла. При сохранении изменения записываются обратно в файл.
